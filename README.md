# Sarbjeet Singh's Portfolio

This is my personal portfolio website, created with HTML, CSS, and JavaScript. I customized the course portfolio template to introduce myself, display my projects, share my GitHub profile, and provide an interactive contact form.

## About Me

I am an aspiring Full Stack Developer who enjoys building clean, responsive, and user-friendly websites. I am continuing to improve my front-end and back-end development skills while learning new web technologies.

## Website Features

- Animated and responsive navigation bar
- Video background with an introduction section
- About Me section
- Responsive project cards
- Automatic, responsive image slideshow
- Previous and next slideshow controls
- Clickable slideshow navigation dots
- GitHub profile section
- Pop-up contact form with open and close controls
- Name, email, and message validation with clear error messages
- On-page success message without sending information to an external service
- Responsive footer with contact information
- Hover effects and responsive layouts for different screen sizes

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Git and GitHub
